# Code of Conduct

## Our Standards

We expect everyone participating in Do More Soft repositories to:

- Be respectful and professional in all communication.
- Focus feedback on technical content, not on the person.
- Assume good intent, and clarify before escalating.
- Respect confidentiality — do not share private project details, credentials, or client information in public channels.

Unacceptable behavior includes harassment, personal attacks, discrimination, publishing others' private information, and any conduct that would be inappropriate in a professional setting.

## Scope

This Code applies to all activity in `Do-More-Soft` repositories: issues, pull requests, discussions, commits, reviews, and any official communication channel.

## Enforcement

Report concerns to **[contact@domoresoft.com](mailto:contact@domoresoft.com)**. All reports are reviewed confidentially. Maintainers may remove, edit, or reject contributions, comments, or accounts that violate this policy.

---

*Do More Soft is a professional software organization. We keep the standard high so that technical work stays the focus.*
