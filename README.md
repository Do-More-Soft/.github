# .github

Organization-level community health files for [Do More Soft](https://github.com/Do-More-Soft).

This repository provides default templates and policies inherited by all repositories under the `Do-More-Soft` organization when they do not define their own.

## Contents

| File | Purpose |
|---|---|
| [profile/README.md](profile/README.md) | Public organization profile displayed on [github.com/Do-More-Soft](https://github.com/Do-More-Soft) |
| [SECURITY.md](SECURITY.md) | Responsible disclosure policy |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Community standards |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Default PR template |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE/) | Default issue forms |
